# 🐍 Desafio: Contagem de Vogais em Tupla

Repositório dedicado à resolução do desafio de identificação e exibição de vogais utilizando a Linguagem Python. O objetivo principal deste projeto é praticar a manipulação de estruturas de dados imutáveis (tuplas) e o controle de fluxo com laços de repetição.

---

## 🚀 Tecnologias Utilizadas

* **Python 3** (Estruturas de dados e lógica de programação)
* **Visual Studio Code** ou IDE equivalente

---

## 📂 Estrutura do Repositório

O projeto conta com uma estrutura simples e direta:

* **`desafio_vogais_tupla.py`**: Código-fonte principal onde está armazenada a lista/tupla de palavras, a lógica de varredura dos caracteres e a exibição das vogais encontradas para cada termo.
* **`README.md`**: Documentação oficial deste repositório.

---

## 🎮 Funcionamento do Desafio

O programa foi desenvolvido para resolver o seguinte cenário:
1. Definir uma tupla contendo várias palavras (ex: `('aprender', 'programar', 'python')`).
2. Percorrer cada palavra presente nessa estrutura.
3. Para cada palavra, identificar quais são as suas vogais (desconsiderando acentuações ou tratando maiúsculas/minúsculas).
4. Exibir o resultado formatado no terminal para o usuário.

---

## 🧠 Conceitos Praticados e Aprendizados

A construção deste script permitiu consolidar fundamentos importantes de manipulação de dados em Python:

* **Tuplas (`tuple`)**: Compreensão e uso de coleções de dados ordenadas e imutáveis em Python.
* **Laços de Repetição Aninhados (`for` loops)**: Utilização de um laço externo para iterar entre as palavras da tupla e um laço interno para inspecionar cada letra individualmente.
* **Manipulação de Strings**: Aplicação de métodos de string (como `.lower()`) para padronizar a verificação dos caracteres.
* **Operadores de Associação (`in`)**: Uso do operador `in` para checar de forma rápida e elegante se uma letra pertence ao grupo de vogais determinado `('a', 'e', 'i', 'o', 'u')`.
